# Halo NRP Project

An interactive strategic map of the Halo universe's Orion Arm, using approximate two-dimensional coordinates centered on Sol at **0, 0**.

## Interactive map

Once GitHub Pages is enabled, open:

https://theevancat.github.io/halo-nrp-project/

## Current features

- Pan and zoom across the coordinate map
- Search for mapped systems
- Toggle UNSC, Covenant, Forerunner, labels, and low-confidence locations
- Distinguish UNSC Inner Colonies, UNSC Outer Colonies, Covenant worlds, and Forerunner installations
- Inspect coordinates, classification, confidence, and associated worlds
- Display the first associated world in system labels, such as **Sol (Earth)**

Coordinates are working estimates derived from the supplied reference map and can be refined as the project develops.
